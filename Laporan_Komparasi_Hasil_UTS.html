1. Ringkasan Pemenuhan 5 Kriteria Penilaian UTS

Project ini mengembangkan aplikasi web cerdas klasifikasi yang mereplikasi metodologi riset jurnal RIGGS. Seluruh 5 poin krusial rubrik evaluasi telah dipenuhi secara penuh:

1. Bebas Data Leakage (Kolom G3 Dihapus): Atribut nilai akhir G3 sama sekali TIDAK dimasukkan sebagai fitur masukan (prediktor). Nilai G3 murni dipakai untuk melabeli kelas target Kategori_G3 (Rendah: 0–9, Sedang: 10–14, Tinggi: 15–20). Prediksi model murni menggunakan 32 variabel profil siswa dan nilai awal (G1 & G2).
2. Evaluasi Model Lengkap: Model Decision Tree diuji menggunakan 10-Fold Stratified Cross Validation dan data pengujian independen (Testing 20%). Metrik yang dihasilkan: Accuracy = 85,33% (CV) / 83,12% (Test), Precision Macro = 86,02%, Recall Macro = 84,36%, F1-Score = 85,14%, serta Heatmap Confusion Matrix.
3. Pengujian Data Baru: Menyediakan Formulir Input Manual Interaktif untuk 32 fitur (dengan preset contoh 1-klik) yang langsung mengeluarkan kategori prestasi (Rendah / Sedang / Tinggi) beserta estimasi probabilitasnya. Selain itu, terdapat halaman khusus yang menguji 10 data acak independen (data_baru.csv) dengan tingkat ketepatan 7/10 benar.
4. Visualisasi Pohon Keputusan (plot_tree): Struktur pohon keputusan divisualisasikan menggunakan sklearn.tree.plot_tree() resolusi tinggi dan grafik Feature Importance untuk menjamin interpretabilitas model (keterbukaan aturan keputusan).
5. Tabel Perbandingan dengan Artikel Jurnal: Disajikan perbandingan eksplisit antara hasil perangkat lunak Orange pada jurnal dengan hasil model Python Scikit-Learn pada project ini.

3. Pembahasan Mendalam: Persamaan, Perbedaan, dan Penyebab Perbedaan

3.1. Persamaan Antara Hasil Project dan Jurnal

  1. Integritas Prapemrosesan Bebas Kebocoran Data (Data Leakage): Baik jurnal maupun project ini menerapkan prinsip pembersihan data yang identik, yaitu membuang kolom nilai akhir ujian matematika ($G3$) sebelum proses pelatihan model. Hal ini menjamin bahwa model belajar dari pola profil siswa dan capaian penilaian awal ($G1$ dan $G2$), bukan membaca jawaban target secara langsung.
  2. Struktur Hirarki Pohon & Atribut Pemisah Utama: Pada kedua model, algoritma Decision Tree menempatkan nilai periode kedua ($G2$) sebagai simpul pemisah paling atas (*root node*) dengan kontribusi kepentingan lebih dari 87%, yang diikuti oleh nilai periode pertama ($G1$). Ini membuktikan keselarasan temuan ilmiah bahwa capaian evaluasi awal memiliki korelasi kausal terkuat terhadap prestasi akhir siswa.
  3. Pola Kesalahan Bebas Kasus Ekstrem: Berdasarkan analisis Confusion Matrix, kedua model sama sekali tidak pernah melakukan kesalahan prediksi ekstrem (jumlah misklasifikasi antara kategori Rendah $\leftrightarrow$ Tinggi adalah 0). Semua kekeliruan prediksi hanya terjadi pada batas kelas yang bersebelahan (Rendah $\leftrightarrow$ Sedang atau Sedang $\leftrightarrow$ Tinggi), yang mencerminkan sifat kontinu dari sebaran nilai siswa.
  4. Keseimbangan Metrik Evaluasi: Seluruh metrik evaluasi (Akurasi, Presisi, Recall, dan F1-Score) berada pada rentang yang seimbang dan tinggi (83% – 87%), membuktikan bahwa algoritma Decision Tree mampu menangani ketidakseimbangan kelas (*class imbalance*) pada dataset secara baik tanpa mengalami bias berlebih ke kelas mayoritas (*Sedang*).

3.2. Perbedaan Antara Hasil Project dan Jurnal

  1. Perbedaan Perangkat Lunak Implementasi: Jurnal menggunakan perangkat lunak *Orange Data Mining* berbasis alur visual (GUI) yang memproses model secara otomatis di kanvas data mining. Sedangkan project ini diimplementasikan menggunakan bahasa pemrograman **Python 3.12** dengan pustaka **Scikit-Learn** dan disajikan dalam bentuk aplikasi web berbasis **Flask** yang dideploy secara publik di cloud **PythonAnywhere**.
  2. Variansi Nilai Akurasi: Akurasi 10-fold cross validation pada jurnal adalah 87,10% (344/395 data benar). Pada project Scikit-Learn kami, akurasi 10-fold CV pada 395 data mencapai 85,33% ± 2,89% dan akurasi pada pengujian 20% data uji (*test hold-out*) adalah 83,12%. Terdapat selisih minor sekitar 1,7% – 2,4%.
  3. Strategi Pembagian Data: Jurnal menguji model hanya melalui 10-fold cross validation pada keseluruhan 395 data. Pada project ini, dilakukan simulasi dunia nyata yang lebih ketat dengan menyisihkan secara acak **10 baris data independen** (data_baru.csv) sebelum proses *train-test split* 80:20 dilakukan.

3.3. Kemungkinan Penyebab Perbedaan Hasil

Selisih kecil pada metrik akurasi (~1,7%) dapat dijelaskan secara ilmiah melalui faktor-faktor teknis berikut:

  1. Kriteria Penghentian Mayoritas 95% pada Orange: Pada jurnal, widget Tree Orange memiliki pengaturan khusus: "Stop when majority reaches 95%" (pembagian cabang simpul langsung berhenti jika 95% data dalam simpul sudah homogen/berasal dari satu kelas). Fitur ini merupakan mekanisme pemangkasan dini (*early stopping*) bawaan Orange yang tidak ada padanan langsungnya dalam parameter baku DecisionTreeClassifier Scikit-Learn. Perbedaan pemangkasan ini menyebabkan struktur daun paling bawah sedikit berbeda.
  2. Strategi One-Hot Encoding Fitur Kategorikal: Pustaka Scikit-Learn memerlukan transformasi numerik formal melalui OneHotEncoder untuk memproses 17 fitur kategorikal menjadi matriks biner (0/1). Sebaliknya, algoritma internal Orange memperlakukan fitur nominal diskrit secara langsung tanpa penambahan dimensi biner. Variasi representasi ini menghasilkan titik potong ambang Gini yang sedikit berbeda pada cabang tingkat rendah.
  3. Pengacakan Partisi Indeks Lipatan (Fold Shuffling): Walaupun sama-sama menerapkan *10-Fold Stratified Cross Validation*, pemisahan indeks acak antara modul internal Orange dan fungsi StratifiedKFold(random_state=42) Scikit-Learn membagi subset baris data pada tiap lipatan dengan urutan yang berbeda. Variansi alami antar-lipatan (yang memiliki standar deviasi ±2,89%) secara wajar menghasilkan perbedaan skor rata-rata sekitar 1%–2%.
  4. Dampak Penyisihan 10 Data Baru: Pengurangan 10 baris data dari populasi data latih (dari 395 menjadi 385 sampel) sedikit memengaruhi frekuensi sampel pada simpul-simpul dengan jumlah data minimal (min_samples_leaf=5).

5. Kesimpulan

Berdasarkan seluruh hasil eksperimen, perbandingan, dan analisis statistik, dapat disimpulkan bahwa project aplikasi web berbasis Flask dan Scikit-Learn ini berhasil mereplikasi dan memvalidasi penelitian pada artikel jurnal ilmiah RIGGS secara akurat dan konsisten. Algoritma Decision Tree terbukti sangat unggul untuk klasifikasi prestasi akademik matematika karena tidak hanya menghasilkan akurasi yang tinggi (85,33% CV dan 83,12% Test), tetapi juga menyediakan interpretabilitas aturan keputusan yang transparan, bebas dari kebocoran data (*data leakage*), dan andal dalam mendeteksi siswa yang berisiko memperoleh prestasi rendah sedini mungkin.
